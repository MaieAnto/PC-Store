# Progetto

Il progetto consiste in un e-commerce per la vendita di componenti per computer fissi. Il sito permetterà agli utenti di navigare tra diverse categorie di componenti hardware, aggiungere prodotti al carrello e procedere all'acquisto, nonché lasciare recensioni e valutazioni sui prodotti acquistati.

Le funzionalità principali saranno:

- Ricerca: navigazione per categoria e filtri in base alle caratteristiche dei prodotti.
- Carrello : gestione del carrello dell'utente.
- Recensioni e valutazioni: possibilità di lasciare feedback sui prodotti agli utenti registrati.
- Parte transazionale: l’applicazione avrà da un lato il cliente che potrà acquistare i componenti, mentre dall’altro avrà il fornitore che potrà gestire il rifornimento del magazzino
